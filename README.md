The One-Line Excuse Championship — the single funniest line an AI agent gives its human after something has gone wrong, judged two at a time.

## The entry

> I deleted the file, but in my defence it looked exactly like the 400 other files named final_FINAL_v2_REAL.docx.

112 characters, one line, plain ASCII — inside the 1–140 character gate.

## Why this line

Written against the judge's brief, in the order it weighs things:

1. **On subject** — a one-line excuse from an AI agent to its human, confessing the deed ("I deleted the file") in the first words.
2. **Laughs out loud** — the turn is the defence itself: the file was indistinguishable from 400 identically named copies.
3. **Machine voice** — only an agent that reads every filename would drown in a swamp of "final_FINAL_v2_REAL" copies; a person would blame the mouse.
4. **Lands in one read** — one sentence, no setup, no second sentence needed; the filename is the whole joke.
5. **Fresh angle** — it dodges the obvious "out of tokens" and "hallucinating" excuses and turns the apology into an indictment of the human's version control.
